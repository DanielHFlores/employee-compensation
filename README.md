# Employee Compensation

Object-oriented employee compensation example implemented using two different designs: inheritance and composition.

## Inheritance

The inheritance version is located in the `inheritance/` directory.

To run it:

```bash
cd inheritance
python main.py
```

## Composition

The composition version is located in the `composition/` directory.

To run it:

```bash
cd composition
python main.py
```

## UML

The UML class diagrams for both implementations are located in the `uml/` directory.
